# ColorOSFacePass

我希望软件能调用人脸识别，但不希望所有软件都能调用，因此有了这个模块。

- **测试环境**：Tested on ColorOS 16
- **定位**：自用

---

### 借鉴来源

本项目基于以下两个开源项目借鉴与整合：

- **[biometric-bypass](https://github.com/hxreborn/biometric-bypass)**
  - 借鉴起步 Commit：[`c710ac8`](https://github.com/hxreborn/biometric-bypass/commit/c710ac84dd65ae81a70475b03fd572e87a4045fd)
- **[FaceBiometricFix](https://github.com/WAYYYAW/FaceBiometricFix)**
  - 借鉴起步 Commit：[`6462515`](https://github.com/WAYYYAW/FaceBiometricFix/commit/64625153e66ac48369656c528168cf2821ee5d9d)（对应版本 tag [v2.1](https://github.com/WAYYYAW/FaceBiometricFix/commit/d5b18e0569409e744dae7c16fa73dff0a5a7c0f1)）
